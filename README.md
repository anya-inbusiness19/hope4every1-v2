# Hope 4 Every1

Website for Hope 4 Every1, a mobile homeless outreach program in Huntsville, AL.

Pages: Home, Services, About, Get Involved, Contact, Admin (all in `index.html`, switched with the menu).

## Editing the site

1. Open the live site and go to **Admin** (link in the footer).
2. Press **Start editing**, then click any outlined text to change it, or **Replace** on a photo.
3. Press **Save draft** in the bottom bar. The draft shows only in your browser.
4. Back on **Admin**, press **Download content.json**.
5. In this repo, choose **Add file → Upload files**, drop in `content.json`, and commit.

GitHub Pages updates the live site in about a minute.
